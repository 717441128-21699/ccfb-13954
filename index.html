负片转正

片基取样 · 分通道特性曲线反算 · IT8 扫描仪标定 · WebGL2 加速

① 导入扫描原始文件

把 TIFF / PNG / JPG 拖到这里,或点击选择(可多选,支持 16bit TIFF)

    ② 转换设置

    未取样 自动 = 取全卷最亮 2%(片边未曝光处);手动 = 点预览图片基位置

    ③ 结果

    或直接点单张下载(PNG)

    底片预览(点取片基用)

    显示第一张底片;「在图上点取」激活后,点击片边未曝光处取片基色。

    IT8 色卡标定

    扫一张 IT8 透射色卡(和扫负片同一台扫描仪、同一设置),载入后在图上按 左上→右上→右下→左下 点四个角,再载入色卡参考值文件,即可解出校正矩阵,把扫描仪光源偏色和通道串扰扣掉。
    未选择角点(0/4)

    没有色卡?

    可以先生成一张合成测试卡走一遍流程(验证软件/熟悉操作);正式标定请用实物 IT8 透射卡。

    特性曲线

    横轴 log 曝光量(0 = 18% 中灰),纵轴密度(已扣片基)。三个通道的曲线本来就不同,必须分通道反算。

    从灰阶负片标定新卷

    新卷不认?拍一张灰阶卡(均匀照明,每档差固定曝光,如半档),冲洗扫描后在这里载入, 从最透明(曝光最少)到最黑(曝光最多)依次点色块,软件量出每档密度、生成三通道曲线预设。
    已点 0 个色块

    转换精度自测(合成负片往返)

    从程序化照片按各预设的特性曲线正向合成负片(带片基色、扫描仪光源偏色、通道串扰、噪声、16bit 量化), 再走完整转换流程,和原片比 CIEDE2000。偏色指标在 3×3 面积平均后计算(偏色是面积上的系统误差,逐像素噪声是扫描仪物理属性)。

    GPU / CPU 一致性

    同一负片分别走 WebGL2 和 CPU 参考实现,逐字节对比输出。

    批量性能基准

    36 张 1200 万像素(4000×3000)16bit 负片连续转换,目标 < 120 秒。
